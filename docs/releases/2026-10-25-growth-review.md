# HOS 个人使用版：AI 成长复盘代理

目标：先供本人在 GitHub Pages 使用，不推进短信、充值、支付或商业配置。保留现有内容与功能。

入口：`#/growth`，首页、工具和日志均可进入。

## 已实现

- 五步引导目标、事件、情绪、决策、身体状态；六种成长方向，作品与生活体验补充。
- 各长文本复用已有语音输入，逐次保存草稿。
- 本机结构化复盘与可选 DeepSeek 复盘。云端仅发送当前表单及用户选择的本周摘要；不发送照片，不额外带出全部个人偏好。
- 复盘保存到档案和日志；可回看原始表达与建议依据。
- 七天实验：可编辑动作、锚点、目标次数、基线、成功标准；每日最多一次，可撤销和修改，支持收尾或停止。
- 四指标：到期实验完成率、同类情境重复错误率、典型情绪恢复分钟、实际深度工作小时。缺失不当零、计划时长不当完成时长、同日总量不重复累加。
- 90 天观察目标、首周与最近完整周比较、已复盘周数；不自动声称因果或成功。
- 生活数据手动记录、CSV 模板与导入预览、校验、幂等更新和单条删除。
- 本机照片观察（最多 12 张，压缩存储），下载与删除；不是医学诊断或自动情绪识别。
- 可暂停的应用内提醒、频率、安静时段、动作/音乐跳转；13 周日历邀请供用户导入。
- 成长证据导出，完整档案备份包含新增数据；当前新数据默认保存在设备及账号隔离空间，不开启商业或强制登录流程。

## 明确边界

- 小米、荣耀直连尚未开通。厂商要求健康服务审批和用户授权，本版支持按模板导入真实数据。
- 不提供后台摄像、视频动作识别、照片舌诊或长驻网页外提醒。应用内提醒仅前台可见时触发；关闭网页使用已导入的系统日历提醒。
- DeepSeek 复用现有服务端，云端失败时明确回退本机，不丢原始材料、不虚报 AI 成功。
- 个人 90 天数据是自我观察证据，不是证明“每周复盘导致改变”的随机对照实验。
